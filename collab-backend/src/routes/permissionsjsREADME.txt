[ permissions.js ]

기본적으로 세션을 만든 사람(관리자)만 코드를 수정 가능
관리자가 다른 팀원에게 편집 권한을 주거나 뺏는 기능을 담당
에디터 상단의 "권한 관리" 탭이 이 API를 이용



[ 핵심 용어 설명 ]

▶ UPSERT
   - INSERT + UPDATE의 합성어
   - 레코드가 없으면 INSERT(생성), 있으면 UPDATE(수정)
   - ON CONFLICT (session_id, user_id) DO UPDATE SET can_edit = $3
   - 같은 세션+유저 조합이 이미 있으면 can_edit만 업데이트
   - 없으면 새로 삽입

▶ COALESCE
   - SQL 함수: 여러 값 중 NULL이 아닌 첫 번째 값을 반환
   - COALESCE(sp.can_edit, FALSE)
   - sp.can_edit이 NULL이면(권한 레코드 없음) FALSE 반환

▶ 403 Forbidden
   - HTTP 상태코드: 인증은 됐지만 권한이 없음
   - 로그인은 했지만 이 기능을 쓸 권한이 없는 경우
   - 401(미인증)과 구별: 401은 로그인 자체가 안 됨
