[ notificatiom.js ]

@멘션이나 권한 변경 시 생성된 알림들을 조회하고 읽음 처리 기능
사이드바의 🔔 알림 버튼이 해당 API들을 사용



[ 핵심 용어 설명 ]

▶ LIMIT
   - SQL: 조회 결과 개수를 제한
   - LIMIT 50 = 최대 50개만 가져옴
   - 알림이 수천 개여도 50개만 표시해서 성능 보호

▶ COUNT(*)
   - SQL 집계 함수: 조건에 맞는 행 수를 셈
   - SELECT COUNT(*) = 전체 행 수 반환
   - 결과가 문자열로 오므로 parseInt()로 숫자 변환 필요

▶ 30초 폴링 방식
   - 프론트에서 30초마다 알림 API를 반복 호출
   - 실시간 소켓 대신 폴링 사용: 알림은 즉시성이 덜 중요
   - 소켓은 에디터 코드 동기화처럼 즉시성이 중요한 곳에만 사용
