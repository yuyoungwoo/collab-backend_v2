[ auth.js ]

사용자가 회원가입하고, 로그인하고, 탈퇴하는 모든 과정을 처리
특히 경성대 이메일(@ks.ac.kr)만 가입 가능하도록 이메일 인증을 3단계로 나뉨

1단계: 이메일 입력 → 인증 코드 발송 (/send-code)
2단계: 6자리 코드 입력 → 코드 검증 (/verify-code)
3단계: 나머지 정보 입력 → 회원가입 완료 (/register)



[ 핵심 용어 설명 ]

▶ Router (라우터)
   - 쉽게 말하면: "URL 안내판"
   - 어떤 URL로 요청이 왔을 때 어떤 함수를 실행할지 연결해줌
   - router.post('/login', ...) → POST /api/auth/login 요청이 오면 이 함수 실행

▶ Route (라우트)
   - URL 경로 + HTTP 메서드의 조합
   - GET /api/snippets → 스니펫 조회
   - POST /api/auth/login → 로그인

▶ HTTP 메서드
   - GET    = 데이터 조회 (가져오기)
   - POST   = 데이터 생성 (보내기)
   - PATCH  = 데이터 일부 수정
   - DELETE = 데이터 삭제

▶ bcrypt (비크립트)
   - 비밀번호를 안전하게 암호화하는 도구
   - 쉽게 말하면: 비밀번호를 알아볼 수 없는 암호문으로 바꾸는 기계
   - 단방향 해시: 암호화는 되지만 복호화(원래대로 되돌리기)는 불가능
   - 왜 단방향인가: DB가 해킹당해도 원본 비밀번호를 알 수 없음
   - bcrypt.hash('비밀번호', 10) → 암호화된 해시값 생성
   - bcrypt.compare('입력값', '저장된해시') → 일치 여부 확인

▶ JWT (JSON Web Token)
   - 로그인 성공 시 발급하는 "디지털 출입증"
   - jwt.sign(데이터, 시크릿키, {expiresIn:'7d'}) → 토큰 생성 (7일 유효)
   - 토큰 안에 userId, name, studentId가 암호화되어 담겨있음
   - 이 토큰을 가지고 있으면 다시 로그인하지 않아도 됨

▶ nodemailer (노드메일러)
   - Node.js에서 이메일을 보내는 라이브러리
   - Gmail SMTP를 통해 실제 이메일 발송
   - transporter = 이메일 발송 도구 객체

▶ req.body
   - POST 요청으로 전송된 데이터 (프론트에서 보낸 JSON)
   - 예) { studentId: '20231234', password: '비밀번호' }

▶ async/await
   - 비동기 처리 방식
   - async 함수 안에서 await를 쓰면 작업이 완료될 때까지 기다림
   - DB 조회, 이메일 발송 같은 시간이 걸리는 작업에 필요

▶ try/catch
   - try 블록: 실행할 코드
   - catch 블록: 에러가 발생하면 여기서 처리
   - 서버 오류로 팅기지 않게 에러를 안전하게 잡아줌



[ 코드 흐름 ]

[이메일 인증 코드 발송 /send-code]
1. 이메일이 @ks.ac.kr로 끝나는지 확인 → 아니면 400 에러
2. 이미 가입된 이메일인지 확인 → 있으면 400 에러
3. 6자리 랜덤 코드 생성
4. 만료 시각 계산 (현재 + 10분)
5. 기존 코드 삭제 후 새 코드 DB 저장
6. nodemailer로 실제 이메일 발송

[코드 검증 /verify-code]
1. 이메일 + 코드로 DB에서 미사용 코드 조회
2. 없으면 400 에러 (잘못된 코드)
3. 만료됐으면 400 에러
4. 코드를 used=TRUE로 업데이트 (재사용 방지)
5. 성공 응답

[회원가입 /register]
1. 모든 필드 입력됐는지 확인
2. @ks.ac.kr 이메일인지 확인
3. 이메일 인증 완료 기록 있는지 확인
4. 학번/이메일 중복 확인
5. 비밀번호 bcrypt 해시화
6. DB에 유저 저장
7. JWT 토큰 발급 후 응답



[ 이 파일에서 사용하는 라이브러리 ]

▶ express
   - 웹 서버 프레임워크. Router() 객체로 URL 경로를 관리함

▶ bcryptjs
   - 비밀번호 단방향 암호화 라이브러리
   - hash(): 비밀번호 → 해시값 변환
   - compare(): 입력값과 해시값 비교

▶ jsonwebtoken (jwt)
   - JWT 토큰 생성/검증 라이브러리
   - sign(): 토큰 생성
   - verify(): 토큰 검증

▶ nodemailer
   - 이메일 발송 라이브러리
   - createTransport(): 발송 설정 객체 생성
   - sendMail(): 실제 이메일 발송
