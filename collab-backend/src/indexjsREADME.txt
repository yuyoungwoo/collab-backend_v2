[ index.js ]

서버가 시작될 때 제일 처음 실행되는 파일, 각 파일들(라우터, DB, 소켓 등)을
해당 파일에서 하나로 모아서 조합함.



[ 핵심 용어 설명 ]

▶ CORS (Cross-Origin Resource Sharing)
   - 브라우저 보안 정책: 다른 출처(포트)의 요청을 기본적으로 차단
   - 프론트(5173포트)에서 백엔드(3000포트)로 요청하면 차단됨
   - cors 미들웨어: 특정 출처의 요청만 허용하도록 설정
   - 쉽게 말하면: "5173포트에서 오는 요청은 허용해줘"

▶ express.json()
   - POST 요청의 body(본문)를 JSON으로 파싱하는 미들웨어
   - 이게 없으면 req.body가 undefined
   - 반드시 라우터보다 먼저 등록해야 함

▶ http.createServer(app)
   - Express 앱을 HTTP 서버로 감싸는 이유:
     Socket.io가 같은 포트에서 WebSocket 연결을 처리하려면
     HTTP 서버 객체가 필요하기 때문

▶ process.exit(1)
   - 서버 프로세스를 강제 종료
   - 1 = 비정상 종료 (오류 발생)
   - 0 = 정상 종료
   - DB 연결 실패 시 서버를 시작시키지 않기 위해 사용



[ 코드 흐름 ]

1. dotenv로 .env 파일 환경변수 로드
2. Express 앱 생성
3. HTTP 서버 생성 (Socket.io 공유용)
4. Socket.io 서버 생성
5. CORS, JSON 파싱 미들웨어 등록
6. 헬스체크 API 등록 (/api/health)
7. 5개 라우터 연결 (auth, sessions, snippets, permissions, notifications)
8. 404, 500 에러 핸들러 등록
9. Socket.io 이벤트 핸들러 등록
10. DB 테이블 생성 완료 후 서버 시작
